# Safe Offhand

Safe Offhand is a lightweight client-side Fabric mod that helps prevent accidental swaps to the offhand.

It adds lockable hotbar slots. When a locked hotbar slot is selected, pressing the offhand swap key will be blocked. Unlocked slots still work normally, and inventory-based offhand swaps remain unchanged.

## Features

* Adds lockable hotbar slots
* Blocks the offhand swap key for locked hotbar slots
* Allows offhand swaps from unlocked hotbar slots
* Keeps normal inventory interactions unchanged
* Configurable through Mod Menu
* Client-side only

## How it works

If you select a locked hotbar slot and press your offhand swap key, Safe Offhand prevents that item from being moved to your offhand.

If the selected slot is unlocked, the offhand swap works normally.

Opening your inventory and using the offhand swap key on hovered items still works like vanilla Minecraft.

## Configuration

Safe Offhand can be configured through Mod Menu.

You can configure:

* Whether the mod is enabled
* Whether actionbar messages are shown
* Which hotbar slots are locked or unlocked

## Requirements

* Fabric Loader
* Fabric API
* Cloth Config
